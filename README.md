# سیستم مدیریت دروس دانشجویی

مجموعه‌ای از دو ابزار وب‌محور برای برنامه‌ریزی درسی، تشخیص تداخل و مدیریت زمان دانشجویان. این دو اپلیکیشن کاملاً مستقل هستند اما با یکدیگر مکمل بوده و یک چرخه‌ی کامل از انتخاب واحد تا نمایش برنامه‌ی هفتگی را پوشش می‌دهند.

---

## ساختار پروژه

```
.
├── index.html                # صفحه‌ی اصلی (لندینگ)
├── weekly schedule.html      # برنامه‌ی هفتگی تعاملی
├── course planner.html       # سیستم انتخاب واحد هوشمند
└── README.md                 # مستندات پروژه
```

---

## ابزارها

### ۱. سیستم انتخاب واحد هوشمند (`course planner.html`)

ابزاری کامل برای ثبت و مدیریت دروس با قابلیت‌های پیشرفته:

- **ثبت درس** با کد، کد ارائه، نام، استاد و چندین بازه‌ی زمانی (کلاس)
- **تشخیص خودکار تداخل** کلاس‌ها و امتحانات با یکدیگر
- **اولویت‌بندی** با جابجایی ردیف‌ها (بالا/پایین) و ذخیره‌ی ترتیب دلخواه
- **کپی سریع** کد درس، کد ارائه، نام استاد، زمان‌های کلاس و اطلاعات کامل هر ردیف
- **جستجو و فیلتر** بر اساس کد، نام، استاد یا کد ارائه
- **پشتیبانی از تاریخ شمسی** برای امتحانات با تبدیل خودکار به فرمت ISO
- **خروجی JSON** (فایل `classes.json`) جهت استفاده در برنامه‌ی هفتگی
- **ویرایش و تکثیر** دروس ثبت‌شده
- **ذخیره‌سازی خودکار** در مرورگر (localStorage)

### ۲. برنامه‌ی هفتگی (`weekly schedule.html`)

نمایش گرید تعاملی از برنامه‌ی کلاس‌های هفته:

- **گرید ساعتی** با تفکیک روزها و نمایش هم‌پوشانی‌ها
- **رنگ‌بندی اختصاصی** برای هر درس (بر اساس کد درس)
- **دو تم رنگی**:
  - «دفترچه» (پس‌زمینه روشن با حس کاغذ)
  - «تخته‌سیاه» (پس‌زمینه تیره با حس گچی)
- **پنل امروز و فردا** برای دسترسی سریع به کلاس‌های روز جاری و بعدی
- **نمایش جزئیات امتحان** با هاور روی کارت درس (کد درس، تاریخ و ساعت امتحان)
- **بارگذاری فایل `classes.json`** خروجی از سیستم انتخاب واحد
- **پیمایش صفحه‌کلید** در جدول برنامه
- **حالت تیره/روشن** خودکار بر اساس تنظیمات سیستم

## نحوه‌ی استفاده (چرخه‌ی کاری)

1. صفحه‌ی اصلی (`index.html`) را باز کنید.
2. روی دکمه‌ی **«ورود به سیستم»** کلیک کنید تا وارد **سیستم انتخاب واحد** شوید.
3. در سیستم انتخاب واحد:
   - دروس خود را ثبت کنید (حداقل یک بازه‌ی زمانی معتبر برای کلاس وارد کنید).
   - تداخل‌های احتمالی را بررسی و در صورت نیاز اولویت ردیف‌ها را تغییر دهید.
   - با دکمه‌ی **دانلود JSON** فایل `classes.json` را ذخیره کنید.
4. به صفحه‌ی اصلی بازگردید و روی **«مشاهده برنامه»** کلیک کنید تا وارد **برنامه‌ی هفتگی** شوید.
5. در برنامه‌ی هفتگی:
   - با دکمه‌ی **وارد کردن**، فایل `classes.json` را بارگذاری کنید.
   - برنامه‌ی کلاس‌های خود را به صورت گرید مشاهده کنید.
   - از پنل امروز/فردا و حالت‌های نمایش مختلف استفاده کنید.

## نیازمندی‌ها

- مرورگر مدرن (Chromium 90+, Firefox 88+, Safari 14+, Edge 90+)
- جاوااسکریپت فعال
- پشتیبانی از `localStorage` برای ذخیره‌سازی داده‌ها
- (اختیاری) File System Access API برای ذخیره‌سازی تنظیمات در فایل `setting.json` در برنامه‌ی هفتگی

## توسعه و مشارکت

هر دو ابزار به‌صورت کاملاً مستقل و با استفاده از HTML، CSS و JavaScript خالص (بدون وابستگی به کتابخانه‌های خارجی) توسعه داده شده‌اند. برای تغییر یا افزودن قابلیت، می‌توانید هر فایل را جداگانه ویرایش کنید.

**نکات فنی مهم:**
- داده‌ها در `localStorage` با کلید `courseSelectionData_v8` ذخیره می‌شوند.
- تاریخ‌های شمسی با استفاده از توابع داخلی به ISO تبدیل می‌شوند.
- تشخیص تداخل بر اساس برخورد بازه‌های زمانی در روزهای مشابه انجام می‌شود.
- برنامه‌ی هفتگی از فیلتر SVG برای ایجاد ظاهر دست‌نویس (sketchy) روی کارت‌ها استفاده می‌کند.

برای مشارکت، لطفاً یک Issue یا Pull Request در مخزن گیت‌هاب ایجاد کنید.
